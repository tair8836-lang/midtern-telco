# Telco Customer Churn Prediction

## Описание проекта
Проект посвящён анализу оттока клиентов телекоммуникационной компании и построению модели машинного обучения для прогнозирования ухода клиентов.

## Данные
- 7043 записи о клиентах.
- Целевая переменная: Churn.
- Проведена очистка и подготовка данных.
- Созданы дополнительные признаки и закодированы категориальные переменные.

## Результаты
- Dummy model Accuracy: 73.46%
- Simple model Accuracy: 79.34%
- Full model Accuracy: 80.55%
- Test Accuracy: 80.7%

## Вывод
Полная модель показала лучший результат. В дальнейшем можно улучшить качество прогнозирования, подобрать параметры и проверить другие алгоритмы.

- `project (1).ipynb` — ноутбук с анализом и моделью.
